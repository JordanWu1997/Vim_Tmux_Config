Mermaid

Syntax

Basics

  • Comment: %%
  • Escape sequece: "", e.g., "(ESCAPE)"
  • Diagram Type:
    • Flowchart: graph <DIRECTION>
      • TD (Top to Down)
      • LR (Left to Right)
    • Sequence Diagram: sequenceDiagram
    • Gantt Chart: gantt
  • Link and Arrows:
    • -->: Standard arrow
    • <-->: Bi-direction arrow
    • -.->: Dotted line
    • ==>: Think line
    • ---: Open link
